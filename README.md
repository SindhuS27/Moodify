# 🎵 Moodify

Moodify is a music discovery app that curates song recommendations based on your mood — powered by the Spotify Web API.

## 🌈 Features

- 🎭 Mood-based music recommendations
- 🔐 Spotify login with OAuth2 authentication
- 🎧 Fetches real-time track suggestions via Spotify
- 📱 Responsive UI for desktop and mobile
- 💽 Displays album art, song previews, and track info

## 🧠 How it works

1. Select your current mood (e.g. Happy, Sad, Chill, Energetic).
2. Login with your Spotify account.
3. Moodify fetches recommendations using Spotify’s recommendation engine.
4. Enjoy a personalized playlist of songs that match your vibe.

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **API:** Spotify Web API
- **OAuth:** Spotify OAuth2.0 Authentication
